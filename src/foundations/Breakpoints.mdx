Variable: `$mobile-max` = **{breakpoints.mobileMax}** in `src/styles/_breakpoints.scss`.

```scss
@use "../../styles/breakpoints" as bkp;

.example {
  padding: var(--space-2xs);

  @include bkp.above-mobile {
    padding: var(--space-xs);
  }
}
```

Tab heights, padding, and gaps per variant will use these breakpoints when component styles are implemented.
