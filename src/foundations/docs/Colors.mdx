# Colors

The color system separates component-facing semantic tokens from the Sass primitives that provide their values.

## Semantic tokens

Components should consume these CSS custom properties through `var(--token)` instead of using primitive values directly.

<ColorTable caption="Semantic color tokens" rows={semanticColors} />

## Reserved primitives

Official values in `src/styles/_primitives.scss` for upcoming Tabs, Badge, and state styles. Not published as CSS custom properties yet.
