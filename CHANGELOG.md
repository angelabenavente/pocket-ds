# Changelog

## 1.0.0 (2026-10-01)

### Added

- First stable release of Badge, Tab, Tabs, and Text.
- Tab and badge sizing, focus, and colour states aligned with the component spec.
- Install notes for pnpm and npm, including apps that already use React 18.
- A type declaration for the `pocket-ds/styles` import.

## 0.1.0 (2026-09-30)

### Added

- Design tokens and foundation pages for color, typography, spacing, and breakpoints.
- Badge, Tab, Tabs, and Text components.
- Storybook documentation with locale switching and viewports aligned to the breakpoints.
- Accessibility checks in Storybook.
- Unit tests for Badge, Tabs, and Text.
- Continuous integration for lint, format, types, tests, the Storybook build, audits, and licenses.
- Package exports for Tabs, Badge, Text, and the foundation stylesheet.
- A Storybook usage page for installation, variants, and states.
- Vercel configuration for the Storybook build, with a content security policy.
